# AI Shark Tank Agent

> A pitch-practice room for founders: answer investor questions under pressure and walk out with a deal memo.

Early scaffold. The Vite + React shell and the Express API are in place. The 3D room, the three shark agents and the report library are next.

## Planned Pieces

- 3D pitch room with three shark seats
- Three Nebius-backed model sharks with different investor archetypes
- Round-based Q&A, offers, passes and counter-offers
- Deal memos saved in SQLite with a printable HTML view

## Run

```bash
npm install
npm run dev
```
